# 2D Sci-Fi Cybernetic Tower Defense

This is a sci-fi themed Tower Defense game (featuring an integrated circuit/motherboard aesthetic), developed in **Construct 3** as a project for the Visual Programming course. The project demonstrates a robust architecture within event sheets and the implementation of complex logical systems for both enemies and defensive structures.

## Key Mechanics Implemented

* **Wave Spawning System:** Logical generation of enemy waves using well-defined time intervals and progressive difficulty.
* **Turret Logic (Targeting):** Algorithms for range detection, fire rate management, and target prioritization.
* **Upgrade System:** Improvement paths for defensive structures, adding a layer of strategic depth.
* **Difficulty Balancing:** A calibrated ratio between accumulated resources and the attack power required to withstand advanced waves.

## How to inspect the project logic (Source Code)

Since this repository hosts the project's source file, you can analyze the architecture (Event Sheets) directly in your browser, for free, without installing any software:

1. Download the `.c3p` file from the *Files* section of this repository.
2. Go to the [Construct 3 Web Editor](https://editor.construct.net/).
3. Click on **Open File** and select the downloaded `.c3p` file.
4. Navigate to the *Event Sheets* folder on the right panel to explore the underlying logic (e.g., how the spawner communicates with turrets and global variables).
